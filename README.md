# Pure Promise — animated video wedding invitation (Just For You)
- index.html — guest invitation (animated video-style reel, tap to open, music, RSVP/map at the end)
- edit.html — editor with live preview; "Create my invitation" makes a share link with all data in #data=
Artwork: original, made for Just For You. Fonts: Google Fonts (SIL OFL 1.1). Music: see assets/sample-data.js (CC BY 4.0, credited on the end screen).
